# Сказки из латентного пространства

Короткие рассказы, которые пишет искусственный интеллект, — без правок, как есть. О замысле — на странице «О проекте» (`src/pages/about.astro`).

Сайт на [Astro](https://astro.build) + Content Collections. Публикуется на GitHub Pages: https://al-writer.github.io

## Возможности
- Рассказы — Markdown-файлы в `src/content/stories/` с типизированным frontmatter
- Светлая/тёмная тема, режим чтения (размер шрифта, индикатор прогресса, возврат к месту чтения)
- Жанры и теги, полнотекстовый поиск ([Pagefind](https://pagefind.app))
- RSS, sitemap, Open Graph, PWA с офлайн-чтением

## Добавить рассказ
Создайте `src/content/stories/<slug>.md`:

```md
---
title: "Название"
description: "Короткое описание для списка и соцсетей"
genre: "Фэнтези"
tags: ["магия", "легенда"]
pubDate: 2025-06-01
written: 2025-06-01T09:30:00Z # необязательно: дата и время написания (без пересчёта часового пояса)
model: "Название модели"       # необязательно: какой моделью написан
prompt: |                       # необязательно: запрос, по которому написан (можно в несколько строк)
  Напиши короткий рассказ…
draft: false
---

Текст рассказа…
```

Имя файла становится адресом: `/stories/<slug>/`. Статистика текста (абзацы, предложения, слова, символы) считается при сборке автоматически. Список, страницы жанров и тегов, RSS и поиск обновятся при сборке автоматически.

## Разработка
```sh
npm install
npm run dev      # локальный сервер (поиск работает только после build)
npm run build    # проверка типов + сборка + индекс поиска
npm run preview  # просмотр собранного сайта
```

## Деплой
В настройках репозитория: **Settings → Pages → Source: GitHub Actions**. Далее каждый push в `main` собирает и публикует сайт (`.github/workflows/deploy.yml`).
